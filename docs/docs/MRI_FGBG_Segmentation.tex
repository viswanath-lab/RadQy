This note outlines how we derive foreground and background masks for MRI volumes in RadQy. Each section documents one detection method, its assumptions, and the clean-up steps needed so FG/BG pixels are reproducible across datasets.

\section{Introduction}
This document lists the foreground/background (FG/BG) segmentation methods in \texttt{backend/seg/}\allowbreak\texttt{mri}. Each section mirrors a Python module and notes its inputs, thresholds, morphology, and fallbacks so downstream IQMs get consistent masks.

\section{Image Processing Segmenters}
Classical pipelines based on intensity statistics and morphology.

\subsection{OtsuHull \texorpdfstring{(\texttt{OtsuHull.py})}{ (HybridOtsuLegacySeg.py)}}
Legacy variant mirroring the original hybrid Otsu pipeline with more defensive fallbacks \cite{sadri2020mrqy}. This subsection is listed first because it matches the earliest implementation shipped with RadQy.
\begin{AmirAlgo}[OtsuHull foreground/background estimation]
\begin{enumerate}
    \item Input slice $I$; cast to uint16.
    \item Histogram-equalize $I$ to get $H$.
    \item Otsu on $I$ and $H$ to obtain masks $m_1, m_2$ and FG fractions $w_1, w_2$.
    \item Hybrid recombination: $S = w_1 \cdot I + w_2 \cdot H$ (normalize to image range).
    \item Otsu on $S$ to get final mask $M$.
    \item Cleanup: convex hull of $M$ (fallback to hole filling if hull fails).
    \item Outputs: $fg = M$, $bg = 1 - M$.
\end{enumerate}
\end{AmirAlgo}
Notes on the weights and masks: $m_1$ is the Otsu mask on the raw slice $I$, $m_2$ is the Otsu mask on the hist-equalized slice $H$. The weights $w_1 = |m_1| / |I|$ and $w_2 = |m_2| / |I|$ measure how much of each slice is classified as foreground; they scale the raw and equalized images when forming $S = w_1 \cdot I + w_2 \cdot H$ so that the cleaner mask (smaller foreground fraction) influences the recombined image more.

\subsection{Adaptive Border Segmentation (\texttt{AdaptiveBorderSeg.py})}
Single-slice segmenter that estimates background from the image border and keeps the largest non-background component.
\begin{AmirAlgo}[AdaptiveBorder foreground/background estimation]
\begin{enumerate}
    \item Normalize input slice to uint8 via 1st/99th percentile scaling.
    \item Extract border ring (default 12 px each side); compute $\mu,\sigma$ on non-zero border pixels (fallback: full image if border empty).
    \item Mark background where $I < \mu - 1\sigma$.
    \item Morphology: binary closing then opening with $5\times5$ kernel; fill holes.
    \item Foreground = inverse of background; keep largest connected component.
    \item Safety: if FG area $<5\%$, set FG to all-ones (entire slice).
    \item Outputs: $(fg, bg)$ with $bg = 1 - fg$.
\end{enumerate}
\end{AmirAlgo}

\subsection{Hybrid Otsu + Convex Hull (\texttt{HybridOtsuHullSeg.py})}
Modern hybrid approach combining Otsu on raw and histogram-equalized images with convex hull cleanup.
\begin{AmirAlgo}[Hybrid Otsu + Convex Hull]
\begin{enumerate}
    \item Robust-scale input slice to $[0,1]$ via 1st/99th percentiles; cast to uint8 for thresholding.
    \item Compute Otsu masks on raw ($x$) and hist-equalized ($h$) images to get FG fractions $w_1, w_2$.
    \item Recombine: $S = w_1 \cdot x + w_2 \cdot h$.
    \item Otsu on $S$ to obtain mask $M$.
    \item Cleanup: apply convex hull to $M$ (fallback: hole filling if hull unavailable).
    \item Outputs: $(fg, bg)$ with $fg = M$, $bg = 1 - fg$.
\end{enumerate}
\end{AmirAlgo}

\section{Deep Learning Segmenters}
Learned models for FG/BG inference.

\subsection{U-Net (placeholder)}
Planned slot for the learned U-Net FG/BG mask generator.
\begin{AmirAlgo}[U-Net inference pipeline (placeholder)]
\begin{enumerate}
    \item Preprocess: normalize/standardize input slice to network expectations.
    \item Forward pass through U-Net to obtain probability map $P$.
    \item Threshold $P$ (e.g., at 0.5) to get binary mask $M$.
    \item Post-process: optional hole filling, small-component removal, and convex hull if needed.
    \item Outputs: $(fg, bg)$ with $fg = M$, $bg = 1 - fg$.
\end{enumerate}
\end{AmirAlgo}

\section{Notes for Integration}
All segmenters operate per 2D slice and return uint8 masks in $\{0,1\}$. Background is always defined as the complement of foreground to ensure downstream IQMs receive matching shapes and disjoint FG/BG sets.
